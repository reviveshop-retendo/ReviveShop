How linking works

On the console, open System Settings → Nintendo Network ID Settings → Link an Existing ID (or create one). The console opens the account webview on this server at /v1/api/oauth20/authorize; sign in here and the console is linked.

Accounts issue their own OAuth20 access, refresh and service tokens. The web signup/login pages are also browsable at https://{{ request.host.split(':')[0] }}:8000/signup and /login.

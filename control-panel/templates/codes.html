How it works

On the console: eShop → Menu → Redeem a Download Code, then enter the code. Money codes are added through Add Funds → Redeem a Nintendo eShop Card.

3DS camera QR uses the ESHOP:// scheme (the camera shows the eShop bag). It only opens the title's store page — it does not redeem the code; the code must still be typed.

Phone QR opens {{ web_base }}/ecommerce/add?card=<code> — the web redemption page (needs an account linked to the 3DS).
